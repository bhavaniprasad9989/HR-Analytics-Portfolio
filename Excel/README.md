# HR Analytics – Excel

## Project Overview

This project uses Microsoft Excel to analyze employee data and identify workforce patterns, employee attrition trends, compensation levels, job satisfaction, and work-life balance.

The workbook contains 50,000 employee records distributed across two HR data sheets. Excel is used for data organization, calculated categories, PivotTable analysis, and dashboard reporting.

## Workbook Structure

The workbook `Excel_HR_Analytics_Final.xlsx` contains five worksheets:

| Worksheet | Description |
|---|---|
| `HR_data_01` | Employee demographics, attrition, department, education, job role, satisfaction, and hourly rate. |
| `HR_data_02` | Employee income, overtime, performance, working years, work-life balance, and promotion history. |
| `Pivot` | Pivot-based KPI summaries and grouped analysis. |
| `Charts` | Worksheet reserved for chart-based reporting. |
| `Dashboard` | Dashboard worksheet. |

## Data Preparation

- Worked with two employee datasets containing 50,000 records each.
- Used employee identifiers to connect employee information across the two datasets.
- Added an **Age Group** category for age-based analysis.
- Created **Income Band** and **SortIncomeBand** fields for compensation segmentation.
- Created **Promotion Group** and **Sort Promotion Group** fields for promotion-history analysis.
- Organized the data for PivotTable-based reporting.

## Key Performance Indicators

The Excel analysis includes the following metrics:

- Total Employees
- Total Attrition
- Attrition Rate
- Average Monthly Income
- Average Hourly Rate
- Average Working Years
- Average Work-Life Balance

## Analysis Performed

### 1. Attrition Analysis
- Attrition distribution by gender.
- Attrition rate by department.
- Attrition rate by age group.
- Attrition rate by job role.

### 2. Compensation Analysis
- Average monthly income.
- Attrition rate across income bands.
- Average hourly rate of male Research Scientists.

### 3. Employee Experience Analysis
- Average work-life balance by job role.
- Average working years by department.
- Employee satisfaction summaries.

### 4. Promotion Analysis
- Attrition rate by years since last promotion.
- Promotion-history grouping to support comparisons.

## Tools and Excel Features

## Key Business Questions

- Which departments have higher employee attrition?
- How does attrition vary across age groups and job roles?
- Is attrition different across monthly income bands?
- How does work-life balance vary by job role?
- How does time since the last promotion relate to attrition?

## How to Use

1. Download `Excel_HR_Analytics_Final.xlsx`.
2. Open the workbook using Microsoft Excel.
3. Review the two HR data worksheets.
4. Explore the `Pivot` worksheet for summarized analysis.
5. Use the `Charts` and `Dashboard` worksheets to review the visual reporting available in the workbook.
