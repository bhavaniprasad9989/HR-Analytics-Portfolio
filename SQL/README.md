# HR Analytics – SQL

## Project Overview

The HR Analytics project aims to analyze employee data and identify important workforce trends, attrition patterns, and HR performance indicators.

SQL was used to query, organize, and analyze employee records. The analysis includes data aggregation, conditional analysis, joins, and the creation of a consolidated `HRDATA` view to simplify reporting and generate meaningful insights.

## Project Objectives

- Analyze employee data using SQL queries.
- Identify employee attrition patterns.
- Understand workforce distribution across different categories.
- Calculate key HR performance indicators.
- Generate insights to support HR decision-making.

## Tools & Techniques

- MySQL
- SQL Queries
- SELECT Statements
- WHERE Conditions
- GROUP BY and ORDER BY
- Aggregate Functions
- CASE Statements
- Joins
- Views
- KPI Calculations

## Key HR Metrics

- Total Employees
- Employee Attrition
- Active Employees
- Attrition Rate
- Average Monthly Income
- Average Age
- Average Working Years

## Analysis Areas

- Employee attrition analysis
- Department-wise workforce analysis
- Job role analysis
- Age group analysis
- Income band analysis
- Work-life balance analysis
